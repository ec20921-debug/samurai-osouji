# おそうじチェック
毎日のそうじを、写真と時刻で記録する小さなページ。

- 写真は、撮るたびに会社の Telegram グループ（管理グループの「おそうじ」トピック）へ送る（2026-11-21〜）。受け取る側は `samurai-motors-app/v7-operations/OsoujiRelay.gs`
- 送れるのは、シート「おそうじ端末」で名前を書いて認めたスマホだけ。はじめてのスマホは画面の左下に「⏳ 確認コード」が出る
- 電波がない・まだ認めていない時は、スマホの中に取っておいて後で送り直す（左下に「📤 枚数」）。日がかわっても2日前までの分は送る
- スマホの中に残すのは今日の分だけ（数の記録は残る）
- `index.html` は公開している版そのもの。`_build.py` で試作から作り直すと、送信の部分が消えるので使わない
